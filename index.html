dinocode

tiny arms, big diffs

An open-source coding agent for the terminal, written in Rust. Interactive sessions, agent teams and a durable task board for work that spans many conversations.

$dinocode
Get it on GitHub How your data is handled
  • Agent teams. Delegate work through the task board to agents with their own roles, models and permissions.
  • Work in parallel. Editing tasks run in separate Git worktrees and branches, so agents don't step on each other.
  • Keeps track of work. Saved sessions and tasks, plans, traces, costs and evaluations.
  • Connects to your tools. 140+ integrations through MCP, with one-click sign-in where providers allow it.
  • Runs on your machine. Your code and sessions stay local. Only the model and integrations you choose receive data.
